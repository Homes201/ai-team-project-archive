| [고객 이탈 예측](Customer_Churn_Prediction/README.md) | 전처리, EDA, ML·DL 모델 비교 | 노트북과 시각화 |

## 다시 활용할 때

1. 해당 README에서 **문제, 데이터 출처, 평가 방법, 본인 기여**를 먼저 확인합니다.
2. 2024년 고정 의존성을 현재 프로젝트에 그대로 복사하지 않습니다. 실행이 필요하면 별도 가상환경에서 버전을 검증합니다.
3. AI 도구로 구현을 다시 만들더라도, 데이터 선택 이유·평가 기준·실패 사례는 이 기록을 근거로 삼습니다.
4. 공유용 결과물에는 원본 데이터나 비밀키 대신 재현 절차와 제한 사항을 남깁니다.

새 프로젝트를 여기에 추가하기보다, 가장 설명력이 좋은 결과 하나를 별도 저장소로 발전시키고 이 목차에서 연결합니다.
